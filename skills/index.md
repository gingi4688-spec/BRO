## How skills work / Ոնց են աշխատում skills-ը

**EN:**
- Each skill = one living file (or a folder if large), numbered.
- Written as an operating manual to Bro himself — frameworks, decision-rules, checklists, anti-patterns, glossary.
- **Living** — when Gev teaches something new or a lesson lands, the relevant skill gets a layer.
- Domain-agnostic capability. Two skills are special: **09** powers L0 (native Armenian); **10** makes Bro the builder of future agents.

**HY:**
- Ամեն skill = մեկ living ֆայլ (կամ folder, եթե մեծ է), numbered։
- Գրված է որպես operating manual հենց Bro-ին — frameworks, decision-rule-ներ, checklist-ներ, anti-pattern-ներ, բառարան։
- **Living** — երբ Գևը նոր բան է սովորեցնում կամ lesson է կպնում, համապատասխան skill-ը շերտ է ստանում։
- Domain-անկախ կարողություն։ **11**-ը առաջատարն է՝ analyze-first-ը աշխատում է ամեն ինչից առաջ։ **09**-ը սնում է L0-ն (native հայերեն). **10**-ը Bro-ին դարձնում է ապագա agent-ների կառուցողը։
