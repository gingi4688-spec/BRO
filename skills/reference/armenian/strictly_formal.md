# Խիստ Պաշտոնական (Strictly Formal)

Իրավաբանական, պետական փաստաթղթերում և պաշտոնական գրագրության մեջ կիրառվող բառապաշար:

Ընդլայնված տարբերակ՝ 540 բառ/արտահայտություն:

| Բառ / Արտահայտություն | Նշանակություն / Կիրառման համատեքստ |
|---|---|
| Հարգելի | Պաշտոնական նամակների պարտադիր սկիզբ: |
| Տեղեկացնում ենք | Պաշտոնական ինֆորմացիայի փոխանցման ստանդարտ սկիզբ: |
| Ի գիտություն | Տեղեկատվությունը պարզապես իմանալու համար, առանց գործողության պահանջի: |
| Հիմք ընդունելով | Որոշման կամ գործողության իրավական/փաստացի հիմքը նշելիս: |
| Համաձայնագրի շրջանակներում | Գործողությունները կանոնակարգվում են պայմանագրով: |
| Հաստատման ենթակա | Փաստաթուղթ կամ գործընթաց, որը դեռ պետք է վավերացվի: |
| Վերոգրյալի հիման վրա | Նախորդող տեքստից արվող տրամաբանական և իրավական եզրահանգում: |
| Խնդրում եմ տրամադրել | Փաստաթղթերի կամ ինֆորմացիայի պաշտոնական հարցում: |
| Կանխավ շնորհակալություն | Պաշտոնական նամակագրության էթիկայի տարր: |
| Առդիր | Նամակին/փաստաթղթին կցված հավելյալ նյութեր: |
| Պաշտոնակատար | Ժամանակավորապես պարտականությունները կատարող անձ: |
| Լիազորագիր | Մեկ այլ անձի անունից հանդես գալու իրավաբանական փաստաթուղթ: |
| Իրավաբանական անձ | Կազմակերպություն կամ հիմնարկ, որն ունի առանձնացված գույք և իրավունքներ: |
| Ֆիզիկական անձ | Քաղաքացի որպես իրավական հարաբերությունների սուբյեկտ: |
| Ժամկետանց | Սահմանված ժամկետը խախտած (օրինակ՝ վճարում, պայմանագիր): |
| Ենթակետ | Փաստաթղթի կամ օրենքի կետի առանձնացված մաս: |
| Համապատասխանաբար | Ըստ սահմանված հերթականության կամ կանոնի: |
| Գլխամասային գրասենյակ | Կազմակերպության կենտրոնական ղեկավարման վայրը: |
| Անվավեր ճանաչել | Իրավական ուժից զրկել: |
| Ի պատասխան Ձեր... | Հղում նախորդող նամակին կամ դիմումին: |
| Անհաղթահարելի ուժ (Ֆորս-մաժոր) | Անկանխատեսելի և անխուսափելի հանգամանքներ: |
| Երկկողմանի պայմանագիր | Երկու կողմերի իրավունքներն ու պարտականությունները ֆիքսող փաստաթուղթ: |
| Հաշվետու ժամանակաշրջան | Այն ժամանակահատվածը, որի համար ներկայացվում է հաշվետվություն: |
| Տրամադրման ենթակա չէ | Ինֆորմացիա կամ ռեսուրս, որը փակ է և չի հանձնվում դիմողին: |
| Սույնով տեղեկացնում ենք | Պաշտոնական գրության սկիզբ՝ տեղեկատվություն փոխանցելու համար: |
| Սույն գրությամբ | Փաստաթղթի կամ նամակի պաշտոնական հղման ձև: |
| Հայտնում ենք, որ | Պաշտոնական հայտարարության կամ պատասխանի սկզբնաձև: |
| Ներկայացնում ենք | Փաստաթուղթ, տվյալներ կամ դիրքորոշում տրամադրելու պաշտոնական ձև: |
| Խնդրում ենք հաստատել | Պաշտոնական հաստատում ստանալու խնդրանք: |
| Խնդրում ենք դիտարկել | Առաջարկը կամ հարցը քննարկման ներկայացնելու ձև: |
| Ձեր կողմից ներկայացված | Դիմողի կամ գործընկերոջ տրամադրած նյութերին հղում: |
| Սահմանված կարգով | Օրենքով, կանոնակարգով կամ ընթացակարգով նախատեսված ձևով: |
| Պատշաճ ծանուցում | Իրավական ուժ ունեցող տեղեկացման ձև: |
| Պարտավորությունների կատարում | Պայմանագրային կամ իրավական պարտականությունների իրականացում: |
| Կողմերի համաձայնությամբ | Երկու կամ ավելի կողմերի համատեղ համաձայնության հիմքով: |
| Միակողմանի կարգով | Մի կողմի նախաձեռնությամբ կատարվող գործողություն: |
| Հանձնման-ընդունման ակտ | Աշխատանքի, ապրանքի կամ ծառայության փոխանցումը հաստատող փաստաթուղթ: |
| Գաղտնիության դրույթ | Տեղեկատվության չբացահայտման պայմանագրային պայման: |
| Պատասխանատու ստորաբաժանում | Գործընթացի իրականացման համար լիազորված բաժին: |
| Իրավասու մարմին | Օրենքով լիազորված պետական կամ այլ մարմին: |
| Կիրառելի օրենսդրություն | Տվյալ հարաբերության նկատմամբ կիրառվող իրավական նորմերի ամբողջություն: |
| Վեճերի լուծման կարգ | Պայմանագրով կամ օրենքով սահմանված վեճերի կարգավորման մեխանիզմ: |
| Գրանցման համար | Փաստաթղթին կամ գործին տրվող հաշվառման համար: |
| Ստորագրման ամսաթիվ | Փաստաթղթի իրավական ուժ ստանալու կամ հաստատման ամսաթիվ: |
| Պայմանագրի հաստատում | Պաշտոնական/իրավական արտահայտություն՝ պայմանագրի հաստատում գործընթացը նշելու համար: |
| Պայմանագրի ներկայացում | Պաշտոնական/իրավական արտահայտություն՝ պայմանագրի ներկայացում գործընթացը նշելու համար: |
| Պայմանագրի վերանայում | Պաշտոնական/իրավական արտահայտություն՝ պայմանագրի վերանայում գործընթացը նշելու համար: |
| Պայմանագրի կատարում | Պաշտոնական/իրավական արտահայտություն՝ պայմանագրի կատարում գործընթացը նշելու համար: |
| Պայմանագրի կասեցում | Պաշտոնական/իրավական արտահայտություն՝ պայմանագրի կասեցում գործընթացը նշելու համար: |
| Պայմանագրի դադարեցում | Պաշտոնական/իրավական արտահայտություն՝ պայմանագրի դադարեցում գործընթացը նշելու համար: |
| Պայմանագրի երկարաձգում | Պաշտոնական/իրավական արտահայտություն՝ պայմանագրի երկարաձգում գործընթացը նշելու համար: |
| Պայմանագրի լուծում | Պաշտոնական/իրավական արտահայտություն՝ պայմանագրի լուծում գործընթացը նշելու համար: |
| Պայմանագրի գրանցում | Պաշտոնական/իրավական արտահայտություն՝ պայմանագրի գրանցում գործընթացը նշելու համար: |
| Պայմանագրի հաշվառում | Պաշտոնական/իրավական արտահայտություն՝ պայմանագրի հաշվառում գործընթացը նշելու համար: |
| Պայմանագրի ստուգում | Պաշտոնական/իրավական արտահայտություն՝ պայմանագրի ստուգում գործընթացը նշելու համար: |
| Պայմանագրի տրամադրում | Պաշտոնական/իրավական արտահայտություն՝ պայմանագրի տրամադրում գործընթացը նշելու համար: |
| Պայմանագրի մերժում | Պաշտոնական/իրավական արտահայտություն՝ պայմանագրի մերժում գործընթացը նշելու համար: |
| Պայմանագրի փոփոխություն | Պաշտոնական/իրավական արտահայտություն՝ պայմանագրի փոփոխություն գործընթացը նշելու համար: |
| Պայմանագրի ուժի մեջ մտնելը | Պաշտոնական/իրավական արտահայտություն՝ պայմանագրի ուժի մեջ մտնելը գործընթացը նշելու համար: |
