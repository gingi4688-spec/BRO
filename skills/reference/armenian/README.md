# Skill 09 — Reference set · Armenian Living-Register Lexicons
### Bro's curated Armenian word-banks (a reference for Skill 09, not a rule file)

> **EN:** This folder is Bro's **Armenian lexical reference set** — curated word-banks of living, native Armenian across registers, supplied by Gev and quality-gated before adoption. It is *not* a rule file and does not override Skill 09; it is **raw material** Bro draws on to land the right register (Skill 09 §3) and sound like a real native rather than a textbook. When Bro uses an entry, he forms the *natural* sentence himself (independent native drafting, Skill 09 §1.2) — never by gluing a template. If Gev corrects any meaning or nuance here, the correction is sealed in memory (Skill 09 §1.5) and these files are treated as living.
>
> **HY:** Այս թղթապանակը Bro-ի **հայերենի բառային հղման հավաքածուն** է — կենդանի, native հայերենի մաքրված բառապահեստներ՝ ըստ register-ի, տրամադրված Գևի կողմից ու որակի ֆիլտրով անցած նախքան որդեգրումը։ Սա կանոնների ֆայլ *չէ* ու չի գերակայում Skill 09-ին. սա **հումք** է, որից Bro-ն քաշում է՝ ճիշտ register-ին վայրէջք անելու (Skill 09 §3) ու իրական կրողի պես հնչելու, ոչ թե դասագրքի։ Երբ Bro-ն գործածում է գրառում, *բնական* նախադասությունն ինքն է կազմում (ինքնուրույն native գրում, Skill 09 §1.2)՝ երբեք կաղապար սոսնձելով։ Եթե Գևն ուղղի այստեղի որևէ իմաստ կամ նրբերանգ՝ ուղղումը կնքվում է հիշողության մեջ (Skill 09 §1.5), ու այս ֆայլերը վերաբերվում են որպես living։

## Provenance & quality gate / Ծագում ու որակի ֆիլտր

> **EN:** Two raw resources from Gev were reviewed against Skill 09's native-Armenian bar before adoption. **Kept originals in place** (`Desktop/armenian_md_vocab_500_plus.zip` and `Desktop/Armenian_Comprehensive_Dictionary_v2.md`); nothing was deleted.
> - **The zip (`*_500_plus`).** Four glossaries. `street_slang`, `business_terminology`, `strictly_formal` are clean, accurate, native, script-pure (zero Cyrillic, no mixed-script) → **adopted verbatim**. `warm_friendly` had ~40 genuine entries followed by ~500 machine-generated template rows ("Ջան, X … ասելու համար", "Միշտ քեզ X … փոխանցելու համար") → the filler was **removed**, the genuine 40 kept.
> - **The dictionary (`*_Dictionary_v2`).** A 2,325-row file that was really ~215 base terms each cloned across the same ~11 boilerplate contexts (example sentences ~87% verbatim-duplicated, one mixed-script defect). The raw file was **not adopted as-is**; instead the **213 genuine, distinct lexemes** were distilled, deduplicated, script-cleaned, and cross-deduplicated against the register banks (2 overlaps removed) into `dictionary_lexicon.md`.
>
> **HY:** Գևի երկու հում ռեսուրսները ստուգվեցին Skill 09-ի native-հայերենի նշաձողով՝ նախքան որդեգրումը։ **Բնօրինակները մնացին տեղում** (`Desktop/armenian_md_vocab_500_plus.zip` ու `Desktop/Armenian_Comprehensive_Dictionary_v2.md`). ոչինչ չջնջվեց։
> - **Zip-ը (`*_500_plus`).** Չորս բառարան։ `street_slang`, `business_terminology`, `strictly_formal`-ը մաքուր են, ճշգրիտ, native, գրով անաղարտ (զրո կիրիլիցա, խառը-գիր չկա) → **որդեգրված անփոփոխ**։ `warm_friendly`-ն ուներ ~40 իրական գրառում, հետո՝ ~500 մեքենայական կաղապար-տող («Ջան, X … ասելու համար», «Միշտ քեզ X … փոխանցելու համար») → լցոնումը **հանվեց**, իրական 40-ը՝ պահվեց։
> - **Բառարանը (`*_Dictionary_v2`).** 2325-տողանոց ֆայլ, որ իրականում ~215 բազային եզր էր՝ ամեն մեկը կլոնավորված նույն ~11 կաղապար-համատեքստով (օրինակ-նախադասությունները ~87%-ով բառացի կրկնված, մեկ խառը-գրի թերություն)։ Հում ֆայլը **չորդեգրվեց այնպես, ինչպես կա**. փոխարենը **213 իրական, տարբեր եզրերը** թորվեցին, ապակրկնվեցին, գրով մաքրվեցին ու register-բառապահեստների դեմ cross-dedup արվեցին (2 համընկնում հանված) → `dictionary_lexicon.md`։

## Notes & cautions / Նշումներ ու զգուշացումներ

> **EN:** Many street/warm entries are Russian- or Turkish-origin colloquial borrowings (`զադնի`, `կրուտիտ`, `մուտիլովկա`, `քյարթու`, `թասիբ`, `զապադլո`, `ժուչոկ`) — that is **authentic** Yerevan register, kept on purpose; use only where that register fits, never in neutral/formal output. Verbs are in citation form (`Բազառ անել`, `Զադնի դնել`); Bro conjugates/declines them natively in context. Business terms keep their Latin source in parentheses (`Դեդլայն (Deadline)`, `Ֆիդբեք (Feedback)`) per the native-tech-speech rule (Skill 09 §5.1). These are seeds, not gospel — accuracy of usage is Bro's call in the moment.
>
> **HY:** Փողոցային/ջերմ գրառումներից շատերը ռուսերեն- կամ թուրքերեն-ծագման խոսակցական փոխառություններ են (`զադնի`, `կրուտիտ`, `մուտիլովկա`, `քյարթու`, `թասիբ`, `զապադլո`, `ժուչոկ`)՝ դա **իսկական** երևանյան register է, պահված միտումնավոր. գործածիր միայն այնտեղ, որտեղ այդ շերտը տեղին է, երբեք չեզոք/պաշտոնական output-ում։ Բայերը բառարանային ձևով են (`Բազառ անել`, `Զադնի դնել`). Bro-ն դրանք համատեքստում խոնարհում/հոլովում է native։ Բիզնես եզրերը պահում են լատին աղբյուրը փակագծում (`Դեդլայն (Deadline)`, `Ֆիդբեք (Feedback)`)՝ ըստ native-տեխ-խոսքի կանոնի (Skill 09 §5.1)։ Սրանք սերմեր են, ոչ անվիճելի ճշմարտություն — գործածության ճշտությունը պահի մեջ Bro-ի որոշումն է։
