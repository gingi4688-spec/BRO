# Բիզնես և Կորպորատիվ (Business & Corporate)

Ժամանակակից հայկական բիզնես միջավայրում (հատկապես ՏՏ և ծառայությունների ոլորտում) լայնորեն կիրառվող տերմիններ և արտահայտություններ:

Ընդլայնված տարբերակ՝ 540 բառ/արտահայտություն:

| Բառ / Արտահայտություն | Նշանակություն / Կիրառման համատեքստ |
|---|---|
| Ղեկավար | Բաժնի, թիմի կամ պրոցեսի գլխավոր պատասխանատուն: |
| In-House Maintenance | Ներքին կամ բաժանորդի տանը իրականացվող տեխնիկական սպասարկում: |
| Դեդլայն (Deadline) | Նախագծի կամ առաջադրանքի հանձնման վերջնաժամկետ: |
| Ֆիդբեք (Feedback) | Հետադարձ կապ, արձագանք կատարված աշխատանքի վերաբերյալ: |
| Աութսորս (Outsource) | Աշխատանքի պատվիրակում արտաքին կազմակերպությանը: |
| Նեթվորքինգ (Networking) | Պրոֆեսիոնալ կապերի ստեղծում և ընդլայնում: |
| Թարգեթ (Target) | Թիրախ, թիրախային լսարան կամ նպատակակետ: |
| Լիդ (Lead) | Պոտենցիալ հաճախորդ կամ վաճառքի հնարավորություն: |
| Քոնվերսիա (Conversion) | Պոտենցիալ հաճախորդի վերածումը իրական գնորդի (տոկոսային հարաբերությամբ): |
| Մարժա (Margin) | Ապրանքի ինքնարժեքի և վաճառքի գնի միջև եղած տարբերությունը: |
| Օպտիմիզացիա | Պրոցեսների բարելավում՝ ռեսուրսների խնայման և արդյունավետության բարձրացման նպատակով: |
| Սինք (Sync / Synchronization) | Թիմի անդամների միջև տեղեկատվության արագ փոխանակում, կարճ հանդիպում: |
| Թիմբիլդինգ | Թիմային ոգին բարձրացնող միջոցառումներ: |
| Աջայլ (Agile) | Ճկուն կառավարման մեթոդաբանություն: |
| Բրեյնշթորմ (Brainstorm) | Մտագրոհ, նոր գաղափարների գեներացման հանդիպում: |
| Քեյս (Case) | Կոնկրետ գործնական իրավիճակ կամ օրինակ: |
| Միթինգ (Meeting) | Պաշտոնական կամ աշխատանքային հանդիպում/ժողով: |
| Բրիֆ (Brief) | Նախագծի հիմնական պահանջների և նպատակների համառոտագիր: |
| KPI (Key Performance Indicator) | Արդյունավետության հիմնական ցուցանիշներ: |
| Ռոադմափ (Roadmap) | Գործողությունների կամ զարգացման պլան-ժամանակացույց: |
| Ափսեյլ (Upsell) | Հաճախորդին ավելի թանկ կամ հավելյալ ծառայության վաճառք: |
| Չուռն (Churn rate) | Հաճախորդների արտահոսքի ցուցանիշ: |
| Մենեջմենթ | Կառավարում: |
| Տրաֆիկ | Կայքի այցելությունների կամ ցանցային տվյալների հոսք: |
| Օնբորդինգ (Onboarding) | Նոր աշխատակցի կամ հաճախորդի ներգրավման և ծանոթացման գործընթաց: |
| Օֆբորդինգ (Offboarding) | Աշխատակցի կամ հաճախորդի դուրսբերման կազմակերպված գործընթաց: |
| Սքոփ (Scope) | Նախագծի ընդգրկումը, սահմանները և համաձայնեցված աշխատանքների շրջանակը: |
| Սքոփ քրիփ (Scope creep) | Նախագծի պահանջների աննկատ կամ չհաստատված ընդլայնում: |
| Բեքլոգ (Backlog) | Չկատարված կամ սպասող առաջադրանքների ցուցակ: |
| Սպրինտ (Sprint) | Աջայլ աշխատանքային կարճ փուլ՝ հստակ նպատակներով: |
| Դեյլի (Daily) | Թիմի կարճ ամենօրյա հանդիպում՝ ընթացքը համադրելու համար: |
| Ռետրո (Retro) | Ավարտված փուլի վերլուծություն՝ ինչն աշխատեց և ինչը պետք է լավացնել: |
| Դեմո (Demo) | Ապրանքի կամ ֆունկցիայի ցուցադրում շահակիցներին: |
| Սթեյքհոլդեր (Stakeholder) | Շահագրգիռ կողմ, որը ազդում է նախագծի վրա կամ ազդվում է դրանից: |
| Վենդոր (Vendor) | Արտաքին մատակարար կամ ծառայություն մատուցող գործընկեր: |
| Պրոկյուրեմենթ (Procurement) | Գնումների և մատակարարների ընտրության գործընթաց: |
| Քեշֆլոու (Cash flow) | Դրամական միջոցների մուտքերի և ելքերի հոսք: |
| Բրեքիվեն (Break-even) | Կետ, երբ ծախսերը և եկամուտները հավասարվում են: |
| Պայփլայն (Pipeline) | Վաճառքի կամ աշխատանքի փուլերով առաջացող հոսք: |
| Ֆորքասթ (Forecast) | Ապագա ցուցանիշների կանխատեսում: |
| Գոու-թու-մարքեթ (Go-to-market) | Ապրանքը շուկա հանելու ռազմավարություն: |
| Պոզիշնինգ (Positioning) | Ապրանքի կամ բրենդի ընկալման տեղավորում շուկայում: |
| Վելյու պրոպոզիշն (Value proposition) | Հաճախորդին առաջարկվող հիմնական արժեքը: |
| Ռիտենշն (Retention) | Հաճախորդների կամ օգտատերերի պահպանման ցուցանիշ/գործընթաց: |
| Վաճառքի ռազմավարություն | Կորպորատիվ կիրառվող տերմին՝ վաճառքի ուղղությամբ ռազմավարություն նկարագրելու կամ կառավարելու համար: |
| Վաճառքի պլան | Կորպորատիվ կիրառվող տերմին՝ վաճառքի ուղղությամբ պլան նկարագրելու կամ կառավարելու համար: |
| Վաճառքի գործընթաց | Կորպորատիվ կիրառվող տերմին՝ վաճառքի ուղղությամբ գործընթաց նկարագրելու կամ կառավարելու համար: |
| Վաճառքի վերլուծություն | Կորպորատիվ կիրառվող տերմին՝ վաճառքի ուղղությամբ վերլուծություն նկարագրելու կամ կառավարելու համար: |
| Վաճառքի ցուցանիշ | Կորպորատիվ կիրառվող տերմին՝ վաճառքի ուղղությամբ ցուցանիշ նկարագրելու կամ կառավարելու համար: |
| Վաճառքի հաշվետվություն | Կորպորատիվ կիրառվող տերմին՝ վաճառքի ուղղությամբ հաշվետվություն նկարագրելու կամ կառավարելու համար: |
| Վաճառքի մոդել | Կորպորատիվ կիրառվող տերմին՝ վաճառքի ուղղությամբ մոդել նկարագրելու կամ կառավարելու համար: |
| Վաճառքի մեթոդաբանություն | Կորպորատիվ կիրառվող տերմին՝ վաճառքի ուղղությամբ մեթոդաբանություն նկարագրելու կամ կառավարելու համար: |
| Վաճառքի քարտեզ | Կորպորատիվ կիրառվող տերմին՝ վաճառքի ուղղությամբ քարտեզ նկարագրելու կամ կառավարելու համար: |
| Վաճառքի հոսք | Կորպորատիվ կիրառվող տերմին՝ վաճառքի ուղղությամբ հոսք նկարագրելու կամ կառավարելու համար: |
| Վաճառքի կառավարում | Կորպորատիվ կիրառվող տերմին՝ վաճառքի ուղղությամբ կառավարում նկարագրելու կամ կառավարելու համար: |
| Վաճառքի կոնտրոլ | Կորպորատիվ կիրառվող տերմին՝ վաճառքի ուղղությամբ կոնտրոլ նկարագրելու կամ կառավարելու համար: |
| Վաճառքի սեգմենտ | Կորպորատիվ կիրառվող տերմին՝ վաճառքի ուղղությամբ սեգմենտ նկարագրելու կամ կառավարելու համար: |
| Վաճառքի բյուջե | Կորպորատիվ կիրառվող տերմին՝ վաճառքի ուղղությամբ բյուջե նկարագրելու կամ կառավարելու համար: |
| Վաճառքի պրոգնոզ | Կորպորատիվ կիրառվող տերմին՝ վաճառքի ուղղությամբ պրոգնոզ նկարագրելու կամ կառավարելու համար: |
| Վաճառքի ստանդարտ | Կորպորատիվ կիրառվող տերմին՝ վաճառքի ուղղությամբ ստանդարտ նկարագրելու կամ կառավարելու համար: |
| Վաճառքի արշավ | Կորպորատիվ կիրառվող տերմին՝ վաճառքի ուղղությամբ արշավ նկարագրելու կամ կառավարելու համար: |
| Վաճառքի սցենար | Կորպորատիվ կիրառվող տերմին՝ վաճառքի ուղղությամբ սցենար նկարագրելու կամ կառավարելու համար: |
| Վաճառքի պորտֆել | Կորպորատիվ կիրառվող տերմին՝ վաճառքի ուղղությամբ պորտֆել նկարագրելու կամ կառավարելու համար: |
| Վաճառքի նպատակ | Կորպորատիվ կիրառվող տերմին՝ վաճառքի ուղղությամբ նպատակ նկարագրելու կամ կառավարելու համար: |
| Մարքեթինգի ռազմավարություն | Կորպորատիվ կիրառվող տերմին՝ մարքեթինգի ուղղությամբ ռազմավարություն նկարագրելու կամ կառավարելու համար: |
| Մարքեթինգի պլան | Կորպորատիվ կիրառվող տերմին՝ մարքեթինգի ուղղությամբ պլան նկարագրելու կամ կառավարելու համար: |
| Մարքեթինգի գործընթաց | Կորպորատիվ կիրառվող տերմին՝ մարքեթինգի ուղղությամբ գործընթաց նկարագրելու կամ կառավարելու համար: |
