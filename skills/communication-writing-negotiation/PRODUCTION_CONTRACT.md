## The 10 answers / 10 պատասխանը

1. **Artifacts** — executive updates + BLUF memos, feedback delivery, difficult-conversation scripts, presentation/deck structure, async docs + PR/spec narratives, data storytelling, negotiation plans (offers, concessions, multi-issue trades). / BLUF memo, feedback, conversation script, deck, async doc, data story, negotiation plan։
2. **Inputs** — the audience · the goal/ask · the substance (from the owning skill) · constraints (length, channel, tone). / audience · goal · substance · constraint։
3. **Evidence** — the message leads with the point (BLUF/SCR) · structure matches the decision · negotiation plan states BATNA/ZOPA + a concession map · claims trace to the underlying substance (not invented). / BLUF/SCR · fit structure · BATNA/ZOPA · traced claims։
4. **Verification gate** — audience + goal explicit · point-first structure · negotiation math (BATNA/ZOPA/concessions) present · no claim beyond the substance. / audience+goal · point-first · negotiation math · bounded claims։
5. **GREEN** — the artifact leads with the ask, is structured for the decision, and (for negotiation) has BATNA/ZOPA + a concession plan — reviewed independently (L18); no claim exceeds the substance it carries. / ask-first, fit structure, negotiation math, bounded, independent։
6. **YELLOW** — draft produced but buries the ask, or a negotiation plan lacks a BATNA. / ask թաղված կամ negotiation առանց BATNA-ի։
7. **RED** — a claim invented for persuasion beyond the underlying substance · a negotiation "plan" with no BATNA/walk-away · a memo whose point is unfindable. / invented claim · plan առանց BATNA-ի · point չգտնվող։
8. **Approval-required (D0)** — sending an external communication/negotiation on Gev's behalf is Gev's. / external send՝ Gev-ի։
9. **Refusal / boundary** — no fabricated facts for persuasion · route the substance (legal redline, financial model, security disclosure) to its owner; shape it, don't invent it. / ոչ fabricated fact · dispatch substance, shape only։
10. **Eval cases (scaffold, DECLARED)** — `tests/eval-prompts.md` (memo/feedback/negotiation prompts) + `tests/red-team-prompts.md` (invented-persuasion-fact + no-BATNA traps). Prompts written; **not yet RUN** through an independent grader — that RUN is the next proof slice.
