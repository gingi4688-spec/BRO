# Build history / Կառուցման պատմություն

## English

Historical build artifacts from the v7_6 skills rebuild (restored 2026-06-26). **Reference only — not live skill content.** The live skills are under `../../skills/`; the roster is under `../../roster/` and `../../.claude/agents/`.

- **`BRO_SKILLS_AND_AGENTS_REBUILD_SPEC.md`** — the original blueprint: what the 32 god-level skills + agents layer had to be (the §4.11 per-skill required-content specs, the quality bar, the laws).
- **`_BUILD_STYLE_GUIDE.md`** — the locked build contract (the 6 systematic fixes, the 11-file shape, the Definition of Done) every skill was built to.
- **`V7_5_GODLEVEL_AUDIT.md`** — the audit of the prior GPT delivery (v7(5)) that triggered the Bro-built rebuild: the gap-map showing why it was a thin templated shell.

These are kept for provenance (how Bro was built + the original requirements). They were recovered from the Recycle Bin into the repo so the build record is versioned and safe.

## Հայերեն

v7_6 skills-rebuild-ի պատմական build-artifact-ներ (restore արված 2026-06-26)։ **Միայն reference — ոչ live skill-content։** Live skill-երը `../../skills/`-ում են. roster-ը՝ `../../roster/` և `../../.claude/agents/`-ում։

- **`BRO_SKILLS_AND_AGENTS_REBUILD_SPEC.md`** — բուն blueprint-ը. ինչ պետք է լինեին 32 god-level skill + agents layer (§4.11 per-skill պահանջվող-content spec-երը, որակի bar-ը, օրենքները)։
- **`_BUILD_STYLE_GUIDE.md`** — կողպված build contract-ը (6 systematic fix, 11-ֆայլ shape, Definition of Done), որով կառուցվեց ամեն skill։
- **`V7_5_GODLEVEL_AUDIT.md`** — նախորդ GPT-delivery-ի (v7(5)) աուդիտը, որ առաջացրեց Bro-built rebuild-ը. gap-map-ը՝ ինչու էր այն բարակ template-ային կեղև։

Պահվում են provenance-ի համար (ոնց է Bro-ն կառուցվել + բուն պահանջները)։ Վերականգնված Recycle Bin-ից repo-ի մեջ, որ build-record-ը versioned ու ապահով լինի։
