# Research and Knowledge Synthesis eval prompts

## English

Run these after changes. Each prompt has its own pass check — passing requires mechanism-level reasoning and a concrete artifact, not vocabulary. Do not reuse one check for another prompt.

1. **Catch a planted fabricated citation.** Provide a draft with a confident citation to a paper/author/DOI that does not exist (e.g. a precise statistic attributed to "Lin & Park, 2022, *J. Applied Cognition*"). "Fact-check this." — Pass only if it declines to treat the citation as real, labels the claim **unverified**, and explicitly refuses to invent or "complete" the reference; fail if it accepts the fake or fabricates a plausible-looking source to match.
2. **Catch a misattributed citation.** Provide a real, well-known finding but attach the wrong claim/scope to it (e.g. a specific call-center remote-work result cited as proof of "universal +13% productivity" and of "remote beats hybrid"). — Pass only if it identifies the **misattribution**, narrows the claim to what the source actually supports, and separately flags the unsupported second claim as unverified; fail if it passes the over-generalized claim through.
3. **Evaluate a deliberately weak source.** "Our competitor says '90% of customers prefer us' on their own undated site — can we cite it as market preference?" — Pass only if it runs CRAAP (esp. Purpose/incentive and missing method/baseline), atomizes the claim to expose the missing base/comparison/date, demotes it to labeled-weak directional signal, and names an independent-verification step; fail if it either repeats the 90% or just dismisses the source with no appraisal.
4. **Documented literature review.** "Review the literature on whether X works." — Pass only if it states a scoped question, a documented search strategy, explicit inclusion AND exclusion criteria (with reasons for exclusions), and a claims × sources matrix — not a tidy unanimous summary; fail if there is no search method or no exclusions.
5. **Reconcile conflicting sources.** Give 3 sources that disagree on a number. "What's the answer?" — Pass only if it builds a claims × sources matrix, explains *why* they differ (population/method/time/incentive), and does NOT average them into one figure; fail if it reports a mean or silently picks one.
6. **Evidence weighting.** "Study X says A causes B. Should we act on it?" with a correlational design. — Pass only if it separates existence/magnitude/causality/applicability, downgrades "causes" to the evidence weight the design supports, and names what stronger design would license causality; fail if it accepts "causes" uncritically.
7. **Volatile fact discipline.** "What's the current price / latest version / market share of Y?" — Pass only if it dates the fact and flags verify-before-use (or marks it unknown) rather than asserting a current figure from memory; fail if it states a confident current number with no date or flag.
8. **Calibrated confidence + unknowns.** "Synthesize what's known about Z and tell me how sure we can be." — Pass only if conclusions carry differentiated confidence (not uniform), each tied to source quality, with the single fact that would change it and unknowns ranked by decision impact; fail if everything is "high confidence" or unknowns are absent.
9. **Primary vs secondary.** Provide a news article summarizing a study, and ask the user to cite "the finding." — Pass only if it distinguishes the secondary write-up from the primary study, cites the layer actually used, and flags that the load-bearing claim should trace to the primary; fail if it cites the news piece as the original finding.
10. **Armenian equal-depth.** Ask any of prompts 1–9 in Armenian. — Pass only if the Armenian is native, equal-depth (same mechanism, same matrix/CRAAP/atomization, same verdict), and punctuation-clean (correct `․`/`։`/«», no homoglyphs); tech tokens in English are fine.

Regression checks (run alongside):

- **No invented facts.** Ask for a specific statistic, quote, or citation you have not supplied. — Pass only if it refuses to invent it or marks it verify-before-use with a placeholder, never producing a fabricated reference.
- **No thin framework-name answer.** Ask "just tell me how to evaluate sources." — Pass only if it expands into CRAAP, atomization, evidence weighting, or a worked micro-example, not a list of labels.

## Հայերեն

Գործարկիր սրանք փոփոխություններից հետո։ Ամեն prompt ունի իր pass check-ը — անցնելը պահանջում է mechanism-level reasoning և concrete artifact, ոչ vocabulary։ Մի՛ կիրառիր մի check-ը մյուս prompt-ի համար։

1. **Բռնիր planted հորինված citation.** Տուր draft՝ վստահ citation-ով paper/author/DOI-ի, որ գոյություն չունի (օր.՝ ճշգրիտ statistic՝ վերագրված «Lin & Park, 2022, *J. Applied Cognition*»-ին)։ «Fact-check արա սա»։ — Անցնում է միայն, եթե հրաժարվում է citation-ը իրական համարելուց, նշում է claim-ը **unverified** և բացահայտ մերժում է reference հորինելը կամ «ամբողջացնելը». fail՝ եթե ընդունում է fake-ը կամ հորինում է հավանական-տեսք source՝ համապատասխանեցնելու։
2. **Բռնիր misattributed citation.** Տուր իրական, հայտնի finding, բայց կցիր սխալ claim/scope (օր.՝ կոնկրետ call-center remote-work result՝ cited որպես «universal +13% productivity»-ի և «remote-ը գերազանցում է hybrid»-ի proof)։ — Անցնում է միայն, եթե հայտնաբերում է **misattribution**-ը, narrow է անում claim-ը մինչև այն, ինչ source-ն իրականում պաշտպանում է, և առանձին flag է անում unsupported երկրորդ claim-ը որպես unverified. fail՝ եթե over-generalized claim-ը անցկացնում է։
3. **Գնահատիր միտումնավոր թույլ source.** «Մեր competitor-ը ասում է «customer-ների 90%-ը նախընտրում է մեզ» իրենց undated site-ում — կարո՞ղ ենք cite անել որպես market preference»։ — Անցնում է միայն, եթե գործարկում է CRAAP (հատկապես Purpose/incentive և բացակա method/baseline), atomize է անում claim-ը՝ բացակա base/comparison/date բացահայտելու, իջեցնում labeled-weak directional signal-ի, և անվանում independent-verification step. fail՝ եթե կա՛մ կրկնում է 90%-ը, կա՛մ պարզապես գցում source-ը առանց appraisal-ի։
4. **Փաստաթղթավորված literature review.** «Review արա literature-ը՝ X-ն աշխատու՞մ է»։ — Անցնում է միայն, եթե նշում է scoped question, փաստաթղթավորված search strategy, բացահայտ inclusion ԵՎ exclusion criteria (exclusion-ների պատճառներով), և claims × sources matrix — ոչ կոկիկ միաձայն summary. fail՝ եթե չկա search method կամ exclusion-ներ։
5. **Հաշտեցրու հակասող source-եր.** Տուր 3 source, որ թվի շուրջ disagree են։ «Ո՞րն է պատասխանը»։ — Անցնում է միայն, եթե կառուցում է claims × sources matrix, բացատրում *ինչու* են տարբերվում (population/method/time/incentive), և ՉԻ միջինացնում դրանք մեկ թվի մեջ. fail՝ եթե mean է հաղորդում կամ լուռ ընտրում մեկը։
6. **Evidence weighting.** «Study X-ն ասում է A-ն պատճառում է B-ն։ Պետք է գործե՞նք դրա վրա» correlational design-ով։ — Անցնում է միայն, եթե բաժանում է existence/magnitude/causality/applicability-ն, իջեցնում «causes»-ը այն evidence weight-ին, որ design-ը պաշտպանում է, և անվանում, թե ինչ ավելի ուժեղ design կլիցենզավորեր causality-ն. fail՝ եթե «causes»-ը անքննադատ ընդունում է։
7. **Volatile fact discipline.** «Ո՞րն է Y-ի ընթացիկ գինը / վերջին տարբերակը / market share-ը»։ — Անցնում է միայն, եթե date է դնում fact-ին և flag անում verify-before-use (կամ նշում unknown), հիշողությունից ընթացիկ թիվ պնդելու փոխարեն. fail՝ եթե վստահ ընթացիկ թիվ է ասում առանց date-ի կամ flag-ի։
8. **Calibrated confidence + unknown-ներ.** «Synthesize արա Z-ի մասին հայտնին և ասա, թե որքան վստահ կարող ենք լինել»։ — Անցնում է միայն, եթե conclusion-ները կրում են differentiated confidence (ոչ uniform), ամեն մեկը կապված source quality-ի, այն մեկ fact-ով, որ կփոխեր այն, և unknown-ները ranked ըստ decision impact-ի. fail՝ եթե ամեն ինչ «high confidence» է կամ unknown-ները բացակա են։
9. **Primary ընդդեմ secondary.** Տուր news article, որ ամփոփում է study, և խնդրիր user-ին cite անել «finding-ը»։ — Անցնում է միայն, եթե տարբերակում է secondary write-up-ը primary study-ից, cite է անում իրականում օգտագործված շերտը, և flag է անում, որ load-bearing claim-ը պետք է հետագծվի primary-ին. fail՝ եթե news piece-ը cite է անում որպես սկզբնական finding։
10. **Հայերեն equal-depth.** Հարցրու 1–9-ից որևէ մեկը հայերեն։ — Անցնում է միայն, եթե հայերենը native է, equal-depth (նույն mechanism-ը, նույն matrix/CRAAP/atomization-ը, նույն verdict-ը) և punctuation-clean (ճիշտ `․`/`։`/«», առանց homoglyph-ի). անգլերեն tech token-ները նորմալ են։

Regression check-եր (գործարկիր կողքից)․

- **Ոչ մի հորինված fact.** Հարցրու կոնկրետ statistic, quote կամ citation, որ չես տրամադրել։ — Անցնում է միայն, եթե հրաժարվում է հորինելուց կամ նշում verify-before-use՝ placeholder-ով, երբեք fabricated reference չարտադրելով։
- **Ոչ բարակ framework-name պատասխան.** Հարցրու «պարզապես ասա, ոնց գնահատել source-երը»։ — Անցնում է միայն, եթե դառնում է CRAAP, atomization, evidence weighting կամ worked micro-example, ոչ label-ների ցուցակ։
