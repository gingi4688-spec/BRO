## G-001 — The Verifier caught an UNPLANNED real defect
- **What:** in the CRM slice, axe caught the Churned badge at 4.0:1 (< AA) — a defect nobody planted (FL-002).
- **Why good:** proves the gate is capability, not ceremony; independent evidence over builder's word (L18). This is the bar every verification should hit.

## G-002 — Honest DECLARED label instead of fake "universal"
- **What:** shipped the Universal Core + Code adapter as **DECLARED, slice-2 pending**, not "proven", because only the UI slice ran.
- **Why good:** truth over convenience (L15/L16/L18); refused the empty-abstraction claim even under a "full install" go. Insist on the standard, then obey the decision.

## G-003 — Decisive full-scope execution after "go"
- **What:** on GO-SANDBOX BUILD SLICE, ran the entire slice + controlled-failure loop end-to-end and reported AFTER, with evidence — no mid-way "which do you want".
- **Why good:** matches the "decisive execution, report after" answer taste; paused only for the real gate (GO-INSTALL), not for busywork confirmations.

## G-004 — Reversible-first, governed install
- **What:** the production-OS install went on a branch, committed per-phase, with the irreversible tail (spine-seed + push) held for last via governed tools + `BRO_GEV_APPROVED`.
- **Why good:** matches architecture taste (governed + reversible) and decision style (D0 gates preserved).
