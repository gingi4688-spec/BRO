# Street Conflict Phrases / Փողոցային Կոշտ Արտահայտություններ

Այս ցանկը ներառում է կոշտ, կոնֆլիկտային կամ փողոցային խոսակցական արտահայտություններ՝ առանց ծայրահեղ գռեհիկ բառապաշարի։
