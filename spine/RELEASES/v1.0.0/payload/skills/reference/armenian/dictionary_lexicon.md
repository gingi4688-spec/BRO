# Skill 09 — Reference · Armenian Living-Register Lexicon
### Native colloquial · slang · warm · professional · formal register vocabulary (a reference for Skill 09)

> **EN:** This is a **reference resource for Skill 09 (Language Mastery)** — a curated, deduplicated lexicon of living Armenian register vocabulary: street slang, business/corporate slang, IT/tech slang, warm/friendly colloquial, and strictly-formal expressions. It is not a rule file; it is a **word-bank** Bro draws on to land the right register (§3 of Skill 09) and to sound like a real native, not a textbook. Source: distilled from a vocabulary file Gev supplied (`Armenian_Comprehensive_Dictionary_v2.md`). That source was machine-padded — ~2,300 rows that were really ~215 base terms each cloned across the same ~11 boilerplate contexts, with example sentences reused verbatim ~87% of the time and one mixed-script defect. The padding and the throw-away example sentences were **dropped**; only the **213 genuine, distinct lexemes with their core meanings** were kept, deduplicated, script-cleaned, and cross-deduplicated against the register word-banks (2 overlaps removed). Treat each entry as a seed: when Bro uses one, he forms the *natural* sentence himself (independent native drafting, §1.2), never the source's boilerplate.
