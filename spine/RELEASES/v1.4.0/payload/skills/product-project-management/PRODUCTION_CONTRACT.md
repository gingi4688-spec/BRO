2. **Inputs** — the problem + user + evidence · constraints · goals/metrics · dependencies · capacity. / problem+user+evidence · constraint · goals · dependency · capacity։
3. **Evidence** — the PRD states the problem + success metric + non-goals · prioritization inputs are labeled (estimate vs data) · the plan's critical path + risks are explicit · DoD = verified-in-running. / PRD problem/metric/non-goal · labeled inputs · critical path · DoD verified-in-running։
4. **Verification gate** — problem-first (not solution-first) · RICE/WSJF inputs sourced or labeled · dependency/critical-path mapped · launch has a learning metric. / problem-first · labeled inputs · critical path · learning metric։

6. **YELLOW** — PRD/plan produced but success metric missing, or RICE scores use unlabeled guesses. / metric չկա կամ RICE առանց label-ի։
7. **RED** — a spec with no problem/metric · invented RICE/impact numbers as fact · a plan with no critical path · "done" claimed without verify-in-running. / spec առանց problem-ի · հորինված RICE · plan առանց critical path-ի · done առանց verify-ի։
