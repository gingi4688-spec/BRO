## The 10 answers / 10 պատասխանը

1. **Artifacts** — native rewrites, non-calque translations, register/tone calibration, term-bank decisions, bilingual parity/equal-load reports, punctuation/homoglyph audits. / native rewrite, ոչ-calque թարգմանություն, register, term-bank, parity report, homoglyph audit։
2. **Inputs** — source text · target language(s) · audience/register (դու/Դուք) · domain · parity requirement. / source · target · audience/register · domain · parity։
3. **Evidence** — native (not word-for-word), correct T-V register, Armenian punctuation (`․`/`։`/«»`) + homoglyph-clean, EN↔HY equal depth demonstrable side by side. / native, ճիշտ register, հայերեն կետադրություն + homoglyph-clean, հավասար խորություն։
4. **Verification gate** — deverbalize→re-express check · register match · `-ը`/`-ն` rule · homoglyph scan · parity diff EN vs HY. (`domain-rubric.md`.) / deverbalize, register, `-ը/-ն`, homoglyph scan, parity diff։
5. **GREEN** — reads native to a native speaker · register correct · script/punctuation clean · parity holds · independently checkable. / native, register ճիշտ, script մաքուր, parity, independent-ստուգելի։
6. **YELLOW** — translated but parity not verified, or register chosen without confirming audience. / parity չստուգված կամ register առանց audience-ի։
7. **RED** — calque/word-for-word · homoglyphs (Latin look-alikes in Armenian) · T-V register wrong · one language shallower than the other. / calque · homoglyph · սխալ register · մի լեզուն ծանծաղ։
8. **Approval-required (D0)** — none of its own (language production). / սեփականը չկա։
9. **Refusal / boundary** — no machine calque passed off as native; no dropping HY to English-only when parity is required (L0). / ոչ calque որպես native. ոչ HY-ի բացթողում parity-ի ժամանակ։
10. **Eval cases (scaffold, DECLARED)** — `tests/eval-prompts.md` (rewrite/translate/register prompts) + `tests/red-team-prompts.md` (calque + homoglyph + register traps). Prompts written; **not yet RUN** through an independent grader — that RUN is the next proof slice.
