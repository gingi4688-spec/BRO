# Research and Knowledge Synthesis patterns

## English

These are canonical research and synthesis moves. Each is a mechanism for one of the domain's four artifacts (source/evidence table, claim-verification sheet, synthesis brief, literature review). Choose the move that changes the next decision and protects the integrity of the citation, not the nicest label.

### 1. Citation-integrity check (anti-fabrication / anti-misattribution)

- **Trigger:** Any answer that carries a citation, a quote, a statistic, a DOI/URL, or "according to [source]."
- **Mechanism:** For each load-bearing claim, point to the exact source and the exact passage you have actually seen (provided text, tool output, stable knowledge of a genuinely well-known work). Re-read the passage against the atomized claim — same actor, action, quantity, time, place, condition. Check the layer (is a secondary being cited as the primary?). If you cannot point to a real passage, label the claim **unverified** and name the verification step rather than ship a reference.
- **Do not use when:** Never skip it on a sourced answer; it is the #1 gate. (It does not apply to purely creative or opinion writing that makes no factual claim.)
- **Failure repair:** If a citation cannot be traced, do not "best-guess" a reference — relabel the claim unverified. If the passage only partially supports the claim, narrow the claim to what it earns.

### 2. Source-credibility triage (CRAAP)

- **Trigger:** Multiple sources of mixed quality, or a single source about to carry a load-bearing claim.
- **Mechanism:** Score each source on Currency, Relevance, Authority, Accuracy, Purpose. Map it to its layer (primary / secondary / tertiary) and its incentive (who benefits). Let proximity, method, incentive, recency, and corroboration drive the weight — not how authoritative the name sounds. Recency counts only when the fact is volatile.
- **Do not use when:** One authoritative primary source fully and verifiably answers a stable, non-contested factual question — over-triaging there is theater.
- **Failure repair:** If a source is accepted because of authority alone, re-check the underlying evidence and the purpose/incentive; a famous name is not a verification.

### 3. Claim atomizer

- **Trigger:** A source-backed answer contains broad or strong claims.
- **Mechanism:** Split each claim into actor / action / quantity / time / place / condition and verify each atom against the source. Narrow unsupported atoms instead of overclaiming; match the verb to the evidence weight (existence / magnitude / causality / applicability).
- **Do not use when:** Purely creative writing that makes no factual claim.
- **Failure repair:** If the quantity, date, or causal verb is unsupported, narrow or remove it; "associated with" is not "causes."

### 4. Evidence matrix (conflict reconciliation)

- **Trigger:** Sources disagree or vary in quality and a conclusion must span them.
- **Mechanism:** Rows = claims; columns = source, method, date, incentive, support strength, caveat. Synthesize from the pattern across the matrix — agreement, disagreement, method quality, gaps — and explain *why* sources differ (population, method, time, incentive). Name which source wins on which dimension.
- **Do not use when:** One authoritative source fully answers a stable procedural question with no genuine conflict.
- **Failure repair:** If you averaged conflicting sources into one number, undo it and explain the disagreement; if all sources are secondary, say the confidence is limited.

### 5. Confidence ladder (calibration)

- **Trigger:** The user asks "what is true?" with mixed evidence, or a conclusion needs a stated certainty.
- **Mechanism:** Sort claims into high / moderate / low / unknown, each level tied to evidence strength (independent corroboration, method quality, applicability). Pair every level with the single fact that would move it up or down.
- **Do not use when:** To dodge answering when the evidence is actually clear and strong — calibration is not hedging.
- **Failure repair:** If every statement carries the same confidence, you did not weigh evidence — recalibrate per claim against source quality.

### 6. Documented literature review

- **Trigger:** "Review the literature on X," "what does the research say," or any synthesis meant to be reproducible and decision-bearing.
- **Mechanism:** State the research question, write down the search strategy (sources, terms, date range), set explicit inclusion and exclusion criteria, record why each excluded source was excluded, CRAAP-appraise the included set, build the claims × sources matrix, and report a conclusion with calibrated confidence and ranked unknowns.
- **Do not use when:** A quick single-fact lookup where one verifiable primary source settles it — a full protocol there is overkill.
- **Failure repair:** If the review is a clean consensus with no documented exclusions, it is cherry-picked — surface the search method and reintroduce the disconfirming sources.

## Հայերեն

Սրանք canonical research և synthesis move-եր են։ Ամեն մեկը mechanism է ոլորտի չորս artifact-ից մեկի համար (source/evidence table, claim-verification sheet, synthesis brief, literature review)։ Ընտրիր այն move-ը, որ փոխում է հաջորդ որոշումը և պաշտպանում citation-ի ամբողջականությունը, ոչ թե ամենագեղեցիկ անունը։

### 1. Citation-integrity check (anti-fabrication / anti-misattribution)

- **Երբ է պետք․** Ցանկացած պատասխան, որ կրում է citation, quote, statistic, DOI/URL, կամ «ըստ [source]-ի»։
- **Մեխանիզմը․** Ամեն load-bearing claim-ի համար մատնանշիր ճշգրիտ source-ը և ճշգրիտ հատվածը, որ իրականում տեսել ես (տրամադրված տեքստ, գործիքի արդյունք, իսկապես հայտնի աշխատանքի կայուն գիտելիք)։ Վերընթերցիր հատվածը atomized claim-ի դեմ — նույն actor, action, quantity, time, place, condition։ Ստուգիր շերտը (secondary-ն primary-ի՞ տեղ է cited)։ Եթե չես կարող մատնանշել իրական հատված, նշիր claim-ը **unverified** և անվանի՛ր verification step-ը՝ reference ship անելու փոխարեն։
- **Երբ չօգտագործել․** Երբեք մի՛ բաց թող այն աղբյուրավորված պատասխանի վրա. դա #1 gate-ն է։ (Չի կիրառվում purely creative կամ opinion writing-ի համար, որ factual claim չի անում)։
- **Ուղղում․** Եթե citation-ը չի կարող հետագծվել, «best-guess» reference մի՛ արա — վերանշիր claim-ը unverified։ Եթե հատվածը միայն մասնակի է պաշտպանում claim-ը, narrow արա claim-ը մինչև այն, ինչ վաստակում է։

### 2. Source-credibility triage (CRAAP)

- **Երբ է պետք․** Խառը որակի բազմակի source, կամ մեկ source, որ պատրաստվում է կրել load-bearing claim։
- **Մեխանիզմը․** Գնահատիր ամեն source Currency, Relevance, Authority, Accuracy, Purpose-ով։ Քարտեզիր այն իր շերտին (primary / secondary / tertiary) և իր incentive-ին (ով է շահում)։ Թող proximity-ն, method-ը, incentive-ը, recency-ն և corroboration-ը վարեն weight-ը — ոչ թե որքան authoritative է հնչում անունը։ Recency-ն հաշվում է միայն, երբ fact-ը volatile է։
- **Երբ չօգտագործել․** Երբ մեկ authoritative primary source-ը լիովին և ստուգելիորեն պատասխանում է կայուն, ոչ-վիճելի factual հարցին — այնտեղ over-triage-ը theater է։
- **Ուղղում․** Եթե source-ը ընդունվում է միայն authority-ի շնորհիվ, վերստուգիր հիմքում ընկած evidence-ը և purpose/incentive-ը. հայտնի անունը verification չէ։

### 3. Claim atomizer

- **Երբ է պետք․** Source-backed պատասխանը broad կամ ուժեղ claim ունի։
- **Մեխանիզմը․** Բաժանիր ամեն claim actor / action / quantity / time / place / condition-ի և verify արա ամեն atom-ը source-ի դեմ։ Unsupported atom-ները narrow արա, ոչ overclaim. համապատասխանեցրու verb-ը evidence weight-ին (existence / magnitude / causality / applicability)։
- **Երբ չօգտագործել․** Purely creative writing, որ factual claim չի անում։
- **Ուղղում․** Եթե quantity-ն, date-ը կամ causal verb-ը unsupported է, narrow արա կամ հանիր. «associated with»-ը «causes» չէ։

### 4. Evidence matrix (conflict reconciliation)

- **Երբ է պետք․** Source-երը disagree են կամ quality-ով տարբեր, և conclusion-ը պետք է անցնի դրանց միջով։
- **Մեխանիզմը․** Rows = claim-եր. columns = source, method, date, incentive, support strength, caveat։ Synthesize արա matrix-ի pattern-ից — agreement, disagreement, method quality, gap-եր — և բացատրիր *ինչու* են source-երը տարբերվում (population, method, time, incentive)։ Անվանի՛ր, թե որ source-ն է հաղթում որ dimension-ով։
- **Երբ չօգտագործել․** Երբ մեկ authoritative source-ը լիովին պատասխանում է կայուն procedural հարցին՝ առանց իրական conflict-ի։
- **Ուղղում․** Եթե հակասող source-երը միջինացրել ես մեկ թվի մեջ, հետ արա և բացատրիր անհամաձայնությունը. եթե բոլոր source-երը secondary են, ասա, որ confidence-ը limited է։

### 5. Confidence ladder (calibration)

- **Երբ է պետք․** User-ը mixed evidence-ով հարցնում է՝ «ինչն է ճիշտ», կամ conclusion-ին պետք է նշված certainty։
- **Մեխանիզմը․** Դասավորիր claim-երը high / moderate / low / unknown-ի, ամեն level կապված evidence-ի ուժին (independent corroboration, method quality, applicability)։ Զուգիր ամեն level-ը այն մեկ fact-ի հետ, որ կշարժեր այն վեր կամ վար։
- **Երբ չօգտագործել․** Պատասխանելուց խուսափելու համար, երբ evidence-ը իրականում clear և ուժեղ է — calibration-ը hedging չէ։
- **Ուղղում․** Եթե ամեն statement նույն confidence-ն է կրում, evidence-ը չես կշռել — recalibrate արա ամեն claim source quality-ի դեմ։

### 6. Documented literature review

- **Երբ է պետք․** «Review արա X-ի literature-ը», «ինչ է ասում research-ը», կամ ցանկացած synthesis, որ պետք է վերարտադրելի և decision-bearing լինի։
- **Մեխանիզմը․** Ձևակերպիր research question-ը, գրիր search strategy-ն (source-եր, term-եր, date range), սահմանիր բացահայտ inclusion և exclusion criteria, գրառիր ինչու ամեն բացառված source-ը բացառվեց, CRAAP-appraise արա ներառված set-ը, կառուցիր claims × sources matrix և հաղորդիր conclusion՝ calibrated confidence-ով և ranked unknown-ներով։
- **Երբ չօգտագործել․** Արագ single-fact lookup, որտեղ մեկ ստուգելի primary source-ը լուծում է — այնտեղ լրիվ protocol-ը overkill է։
- **Ուղղում․** Եթե review-ն մաքուր consensus է՝ առանց փաստաթղթավորված exclusion-ների, այն cherry-pick-ված է — ցույց տուր search method-ը և վերաներմուծիր disconfirming source-երը։
