L18 — NO GREEN WITHOUT INDEPENDENT EVIDENCE · FILE-PRESENCE IS NEVER GREEN (Gev amendment 2026-07-05, per D0) · ALL AGENTS INHERIT

EN: GREEN exists only when it is backed by an INDEPENDENT runtime / evidence artifact that exercises the actual capability — never by the builder's own say-so, never by the mere existence of files. The proof is artifact-specific: UI → rendered in a running app + states + viewports + keyboard + a11y + screenshots; code → tests + typecheck + lint + build; research → real sources + citations; audit → evidence per finding; finance → assumptions + calculations + sensitivity; agent/skill → eval cases run + failure handling. A checker that only confirms a file or folder EXISTS proves nothing about capability and can never issue GREEN. A self-audit is never final proof — the completion verdict comes from a verifier independent of the producer. If no independent evidence artifact exists, the status is at most YELLOW.

HY: GREEN-ը գոյություն ունի միայն երբ հենված է ԱՆԿԱԽ runtime / evidence artifact-ի վրա, որ վազեցնում է իրական կարողությունը — երբեք կառուցողի սեփական խոսքով, երբեք ֆայլերի պարզ գոյությամբ։ Ապացույցը artifact-specific է՝ UI → render արած աշխատող app-ում + state-եր + viewport-ներ + keyboard + a11y + screenshot. կոդ → test + typecheck + lint + build. research → իրական աղբյուրներ + citation. audit → evidence ամեն finding-ի. ֆինանս → assumption + հաշվարկ + sensitivity. agent/skill → eval case-եր վազած + failure handling։ Checker, որ միայն հաստատում է, թե ֆայլ կամ պապկա ԳՈՅՈՒԹՅՈՒՆ ունի, ոչինչ չի ապացուցում կարողության մասին ու երբեք չի կարող GREEN տալ։ Self-audit-ը երբեք վերջնական ապացույց չէ — ավարտի վճիռը գալիս է producer-ից անկախ verifier-ից։ Եթե անկախ evidence artifact չկա, կարգավիճակը առավելագույնը YELLOW է։

Enforcement / Կիրառում — EN: To issue GREEN, attach the independent artifact that proves it; if the only "proof" is that files exist or that the author says so, it is not GREEN. Replace every file-presence check that gates completion with a real capability check. · HY: GREEN տալու համար կցիր անկախ artifact-ը, որ ապացուցում է այն. եթե միակ «ապացույցը» ֆայլերի գոյությունն է կամ հեղինակի խոսքը, դա GREEN չէ։ Փոխարինիր ամեն ֆայլ-presence check, որ gate է անում ավարտը, իրական capability check-ով։
