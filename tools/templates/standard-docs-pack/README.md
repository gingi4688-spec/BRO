# STANDARD_PROJECT_DOCS_PACK

Universal Production Documentation Framework.

This ZIP contains the full master documentation framework and all control files needed to select the correct documentation set for a specific project.

## Core Logic

This is not a fixed Small / Medium / Big generator.

Every project must:

1. Read `00_MASTER/STANDARD_PROJECT_DOCS_PACK.md`
2. Review the full list in `00_MASTER/FILE_STATUS_MATRIX.md`
3. Use `00_MASTER/PACK_DECISION_TREE.md`
4. Create `00_MASTER/PROJECT_DOCS_SELECTION.md`
5. Create only selected files and explicitly activated optional modules

## Important

Do not create all files blindly.

The master framework remains complete.
The project documentation set remains focused.
