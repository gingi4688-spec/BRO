# TEMPLATE_CONVENTIONS.md

Template rules for STANDARD_PROJECT_DOCS_PACK.

## File Naming

Use:

```txt
<UPPERCASE_SNAKE_CASE>.md
```

## Folder Naming

Use:

```txt
NN_CATEGORY_NAME/
```

## Language

Every template should support:

```txt
EN — English
HY — Armenian
```

## Standard Sections

Use these sections unless a file needs a more specific structure:

```txt
Purpose / Նպատակ
Scope / Շրջանակ
Source Inputs / Մուտքային աղբյուրներ
Specification / Սպեցիֆիկացիա
Rules / Կանոններ
Open Questions / Բաց հարցեր
```

## Template Rule

Files in `24_TEMPLATES/` are reusable structures.
They are not project-specific source of truth until copied and filled for a specific project.
