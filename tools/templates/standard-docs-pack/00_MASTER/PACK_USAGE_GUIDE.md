# PACK_USAGE_GUIDE.md

How to use STANDARD_PROJECT_DOCS_PACK.

## Workflow

1. Read `STANDARD_PROJECT_DOCS_PACK.md`.
2. Open `FILE_STATUS_MATRIX.md`.
3. Review the full file list with the user.
4. Run `PACK_DECISION_TREE.md`.
5. Mark each relevant file as MUST, GOOD_TO_HAVE, CONDITIONAL_MUST, ENTERPRISE, TEMPLATE, or NOT_NEEDED.
6. Create `PROJECT_DOCS_SELECTION.md`.
7. Follow `DOCS_DEPENDENCY_GRAPH.md`.
8. Apply `SOURCE_OF_TRUTH_RULES.md` if files conflict.
9. Create and fill only selected project docs.

## Main Rule

The framework is complete.
The project selection must stay focused.
