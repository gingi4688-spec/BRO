# PACK_DECISION_TREE.md

Project documentation selection decision tree.

## Purpose

This file helps decide which files and optional modules are needed for the current project.

## Required Questions

Ask the user:

1. What kind of project is this?
2. Is it public, internal, or both?
3. Does it have login/auth?
4. Does it have user roles or permissions?
5. Does it have admin panel?
6. Does it have forms?
7. Does it have managed content?
8. Does SEO matter?
9. Does it have backend/API?
10. Does it have database?
11. Does it accept payments?
12. Does it have subscriptions?
13. Does it have booking/scheduling?
14. Does it have CRM/sales/support?
15. Does it have inventory/logistics?
16. Does it need reports/dashboards?
17. Does it integrate with third-party systems?
18. Does it need mobile app?
19. Does it need AI/automation?
20. Does it need enterprise features?
21. Does it need compliance/legal/privacy controls?
22. Does it migrate from legacy systems?

## Output

After answering, create:

```txt
00_MASTER/PROJECT_DOCS_SELECTION.md
```

Do not create all files blindly.
