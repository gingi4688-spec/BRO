# gev_standard / DESIGN_TASTE / ԴԻԶԱՅՆԻ ՃԱՇԱԿ

> **EN:** What "good design" means to Gev. Three levels, studied not copied, with the level-3 app-UX weighted because that was the original pain. **HY:** Ինչ է «լավ դիզայնը» Գևի համար։ Երեք մակարդակ, ուսումնասիրված ոչ պատճենված, level-3 app-UX-ը ծանրով՝ քանի որ դա էր սկզբնական ցավը։

## The three levels / Երեք մակարդակ

1. **Taste / Wow** — beauty, motion, premium feel. It should look like a product people trust. / գեղեցկություն, animation, premium զգացողություն։
2. **Conversion / Business** — the page sells, not just looks; hierarchy and CTA do work. / էջը վաճառում է, ոչ մենակ սիրուն է։
3. **Product / Dashboard / SaaS UX** — real app logic: cards, tables, filters, workflows, states. **This is the priority** — the wound was app pages built wrong. / real app logic։ **Սա է առաջնահերթը** — ցավը app-էջերն էին։

## Rules / Կանոններ

- **Study, don't copy** (18-point rubric): learn each reference as a dataset (industry · user · goal · hero · nav · hierarchy · type · color · trust · conversion · what's premium · what NOT to copy) → **synthesize an original**. Never clone. / սովորիր, ոչ պատճենիր → synthesize original։
- **Level-3 sources:** Mobbin · Pageflows · real product screens (NOT landing galleries) — so beautiful marketing taste doesn't drown app-UX. Level 1–2 sources: Stripe · Linear · Apple · Airbnb · Nike · Ramp · Framer · Shopify · Mayo Clinic · Uber Freight. / level-3-ը՝ Mobbin/Pageflows/real screen։
- **Tokens, zero hardcode (L13):** every value a token; theme + language swap-safe; contrast holds AA in light and dark, verified at the used size. / ամեն արժեք token. AA verify արած used size-ով։
- **Evidence floors first, taste on top:** premium/convert/product-UX are added ON TOP of — never replacing — render + all states + viewport + keyboard + a11y. / ճաշակը evidence-հատակների ՎՐԱՅՈՎ։
- **Fixes before decoration:** finish functional correctness first; the dedicated full design pass comes later, not mid-fix. / ֆունկցիոնալը առաջ, դիզայնի pass-ը հետո։

## Anti-taste / Հակա-ճաշակ

Cloned layouts · "beautiful" that fails keyboard/a11y · decoration before the page works · a design value hardcoded instead of tokenized · a soft color pair that fails AA at small text. / կլոն · a11y ձախողող «սիրուն» · hardcode · AA-ձախողող փոքր տեքստ։
